# DriveShare demo accounts

Open [DriveShare on localhost](http://localhost:5173/) and use these seeded accounts. Each account uses `DriveShareDemo!23` in the local development demo.

| Role          | Display name | Email                    | What to show                                                                              |
| ------------- | ------------ | ------------------------ | ----------------------------------------------------------------------------------------- |
| Driver        | Riya Sharma  | `driver@driveshare.demo` | Book or cancel Riverside Court and see the status change.                                 |
| Host          | Meera Nair   | `owner@driveshare.demo`  | Open the host dashboard, find the same booking ID, and view the driver and notifications. |
| Administrator | Aditi Rao    | `admin@driveshare.demo`  | Review a pending parking listing or inspect a fine dispute.                               |

Use a regular browser window for the driver and a private window or a different browser profile for the host. Separate browser sessions keep both accounts signed in while they read and update the same PostgreSQL database. These are fictional demo identities. Payments are simulated. Seeded credentials are for local development only.

See the [five-minute demonstration](HOW_TO_DEMONSTRATE_DRIVESHARE.md) and [advanced classroom scenarios](docs/DEMO_GUIDE.md) for the remaining sample accounts and workflows.
